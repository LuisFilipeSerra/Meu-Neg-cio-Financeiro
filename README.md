
# Meu Negócio Financeiro

## Sobre o projeto

O Meu Negócio Financeiro é um sistema de controle financeiro desenvolvido em Python, voltado para pequenos empreendedores e trabalhadores autônomos.

O projeto busca facilitar a organização das finanças de pequenos negócios, permitindo acompanhar receitas, despesas e o saldo disponível.

## Objetivo

Desenvolver uma aplicação simples, executada pelo terminal, que ajude pequenos empreendedores a compreender sua situação financeira e organizar melhor seus recursos.

## Público-alvo

- Pequenos empreendedores
- Trabalhadores autônomos
- Microempreendedores individuais (MEIs)
- Pessoas que precisam controlar as finanças de pequenos negócios

## Funcionalidades planejadas

- Registrar receitas
- Registrar despesas
- Calcular o saldo financeiro
- Consultar o histórico de movimentações
- Organizar movimentações por categorias
- Exibir um resumo financeiro

## Tecnologias utilizadas

- Python
- Visual Studio Code
- Git e GitHub

## Estado atual do desenvolvimento

O projeto está em sua fase inicial.

A primeira versão contém variáveis para receitas e despesas, realiza o cálculo do saldo e apresenta os resultados no terminal.

As demais funcionalidades serão implementadas nas próximas etapas.

## Como executar

1. Instale o Python 3.
2. Abra a pasta do projeto no VS Code.
3. Abra o terminal.
4. Execute:

```bash
py main.py
```
